A. Вкладки как в IDE

Навигация в виде табов файлов (home.tsx, projects.tsx). Секции как «файлы» в редакторе. Всё на одной странице, табы скроллят к секциям.

⌂ ◈ ✉
~ / portfolio / home
Hello, World!|
I build things that work.
GitHub
Telegram

B. Сайдбар как в VS Code

Боковая панель с иконками навигации. Breadcrumb-путь сверху. Основной контент справа. Ощущение настоящей IDE.

visitor@portfolio:~$ ls sections/
> sadmore_
Full-stack developer
[ projects ] [ contacts ]
project_1/
Bot for images
project_2/
Portfolio site

C. Терминал / CLI

Полностью в стиле терминала. Навигация через «команды» в хедере. Минималистично и хакерски. Скролл вниз по секциям.
