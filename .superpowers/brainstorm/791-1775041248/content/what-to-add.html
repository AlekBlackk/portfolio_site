Что добавить на сайт?

Выбери одну или несколько идей — всё в духе IDE/terminal

A

Секция «About / Skills»

Новый таб about.tsx — немного о себе, стек технологий в виде прогресс-баров или badge-ов в стиле кода. Оформлен как JSON/комментарии.

B

Интерактивный терминал (Easter Egg)

Псевдо-терминал, где пользователь может вводить команды: help, ls projects, cat about.md. Открывается хоткеем (например, Ctrl+~).

C

Timeline / Experience

Опыт работы или учёбы в стиле git log — каждый этап это «коммит» с датой, хэшем и описанием.

D

GitHub Stats / Activity

Плашки со статистикой GitHub (через github-readme-stats) или ASCII-style «contribution graph» прямо на странице.
