# Portfolio Site — Design Spec

## Context

Создание персонального сайта-портфолио в «кодерском» стиле (IDE/terminal aesthetic). Сайт одностраничный, статический, без фреймворков. Размещается в `C:\Users\sadmore\Desktop\site`.

## Решения

- **Структура:** Чистый HTML + CSS + JS (без зависимостей, без сборки)
- **Раскладка:** Вкладки как в IDE (табы-файлы)
- **Цвет акцентов:** Фиолетовый (#a855f7) — cyberpunk стиль
- **Разделы:** Hero, Projects, Contacts (минимальный набор)
- **Данные проектов:** Placeholder, 4 карточки

## Структура файлов

```
site/
├── index.html      — разметка всего сайта
├── style.css       — все стили
├── script.js       — typing-эффект, навигация, анимации
└── assets/         — (по необходимости, превью проектов)
```

## Компоненты

### 1. Title Bar

Полоска сверху, имитирующая окно приложения:
- Три кнопки (красный/жёлтый/зелёный) слева
- Текст `sadmore — portfolio` по центру
- Цвет фона: `#111118`

### 2. Tab Bar (навигация)

Горизонтальные табы, каждый выглядит как файл в IDE:
- `home.tsx` — иконка ⌂
- `projects.tsx` — иконка ◈
- `contacts.tsx` — иконка ✉

Активный таб: цвет текста `#a855f7`, нижняя граница 2px solid `#a855f7`, фон как у body.
Неактивные: цвет `#666`, фон `#0d0d14`.

Клик по табу — плавный скролл к соответствующей секции. При скролле активный таб обновляется через Intersection Observer.

### 3. Hero Section

Оформлен как блок кода с номерами строк:
```
1  // привет, я
2  const developer = {
3    name: "sadmore"
4    role: "Full-Stack Developer|"   ← typing effect + мигающий курсор
5  };
```

- Номера строк — цвет `#c084fc`
- Ключевые слова (`const`) — цвет `#c084fc`
- Имя переменной (`developer`) — цвет `#60a5fa`
- Строковые значения — `#a855f7` для имени, `#34d399` для роли
- Typing-эффект: циклическая смена ролей (например: "Full-Stack Developer", "UI/UX Enthusiast", "Open Source Contributor")
- Мигающий курсор: `|` с CSS animation (blink 1s infinite)

Под кодом — две кнопки:
- `→ GitHub` — залитая кнопка (#a855f7)
- `→ Telegram` — outline кнопка (border #a855f7)

Фоновый эффект: radial-gradient фиолетовый glow за hero секцией.

### 4. Project Cards

Сетка 2x2 (на десктопе), 1 колонка на мобильных.

Каждая карточка:
- **Превью:** Градиентный блок 80-100px высотой с эмодзи-иконкой (позже заменить на скриншот)
- **Название:** 13px, цвет `#a855f7`, font-weight 600
- **Описание:** 11px, цвет `#9ca3af`
- **Теги:** pill-badges (`background: #a855f720`, `color: #a855f7`, border-radius 12px)
- **Ссылка GitHub:** карточка целиком кликабельна

**Hover-анимация:**
- `border-color` переход на `#a855f7` (0.3s ease)
- `transform: translateY(-4px)`
- Лёгкий `box-shadow: 0 8px 24px #a855f710`

4 placeholder-проекта с разными градиентами превью.

### 5. Contacts Section

Минимальный блок:
- Комментарий `// contacts`
- Горизонтальный список ссылок: GitHub, Telegram, Email
- Стиль: `→ Name` с цветом `#a855f7`
- Hover: подчёркивание или glow

### 6. Status Bar

Полоска внизу, как в VS Code:
- Слева: `main` (ветка), `UTF-8`
- Справа: `Ln 42, Col 1`, `TypeScript`
- Фон: `#111118`, шрифт 10px, цвет `#666`
- Фиксированная внизу viewport (position: fixed)

## Визуальные эффекты

### Typing Effect (JS)
- Массив строк-ролей
- Посимвольная печать, пауза, посимвольное удаление, пауза, следующая строка
- Скорость: 80ms/символ печать, 50ms/символ удаление, 2000ms пауза

### Мигающий курсор (CSS)
```css
@keyframes blink { 0%, 50% { opacity: 1; } 51%, 100% { opacity: 0; } }
.cursor { animation: blink 1s infinite; }
```

### Фоновая сетка (CSS)
Тонкая сетка поверх фона через repeating-linear-gradient или SVG-паттерн. Opacity ~0.03-0.05.

### Фиолетовый Glow
Radial-gradient от `#a855f710` в области hero секции. Создаёт ощущение свечения.

### Scroll-анимация карточек
Карточки появляются с `opacity: 0 → 1` и `translateY(20px → 0)` при входе во viewport (Intersection Observer). Staggered delay между карточками.

### Плавные переходы
- Все hover-эффекты: `transition: all 0.3s ease`
- Навигация: `scroll-behavior: smooth`

## Адаптивность

- **Desktop (>768px):** Сетка карточек 2x2, горизонтальные табы
- **Mobile (<768px):** Сетка карточек 1 колонка, табы уменьшаются (можно только иконки), status bar скрывается или упрощается

## Технология

- Чистый HTML5 + CSS3 + Vanilla JS
- Никаких зависимостей
- Google Fonts: JetBrains Mono (или system monospace fallback)
- Intersection Observer API для scroll-анимаций и активного таба
- CSS custom properties для палитры

## Верификация

1. Открыть `index.html` в браузере — убедиться что все секции отображаются
2. Проверить typing-эффект работает и циклически меняет роли
3. Проверить клик по табам скроллит к нужной секции
4. Проверить hover-анимацию карточек
5. Проверить адаптивность на мобильном размере (DevTools → responsive)
6. Проверить scroll-анимацию карточек при прокрутке
7. Убедиться что status bar фиксирован внизу
