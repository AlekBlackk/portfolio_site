# Портфолио

Персональный сайт-портфолио с интерфейсом в стиле IDE. В нём собраны информация обо мне, проекты, контакты и интерактивные элементы.

## Возможности

- адаптивный интерфейс для компьютеров и мобильных устройств;
- навигация по разделам страницы;
- секции «Обо мне», «Проекты» и «Контакты»;
- анимации, плавающие панели и интерактивные эффекты;
- тесты для переиспользуемой логики навигации.

## Стек

- HTML5
- CSS3
- JavaScript
- Node.js (встроенный тестовый раннер)

## Запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/AlekBlackk/portfolio_site.git
   ```

2. Откройте файл `index.html` в браузере.

Для более удобной разработки можно запустить проект через любой локальный статический сервер.

## Тесты

Для запуска всех тестов выполните:

```bash
npm test
```

Зависимости не требуются: тесты используют встроенный тестовый раннер Node.js.

## Структура проекта

```text
portfolio_site/
├── index.html      # разметка сайта
├── style.css       # стили и адаптивность
├── script.js       # интерактивность сайта
├── favicon.svg     # иконка сайта
└── tests/          # автоматические тесты
```
